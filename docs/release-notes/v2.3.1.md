## Release v2.3.1
### What's changed

#### Breaking changes:
* Dropped support for Python 3.10, which reaches end of life in October 2026. promptolution now requires Python >= 3.11 (#87)

#### Further changes:
* Added support for Python 3.13 and 3.14. Python 3.14.1 is excluded because torchvision, a dependency of the `vllm` extra, does not support it. Use 3.14.2 or newer instead (#88)
* Allows Pillow 13.0.0, which fixes several security vulnerabilities, including a critical heap buffer overflow in FlashPix decoding. Pillow 13 requires Python >= 3.11, which is why Python 3.10 was dropped. Pillow is only installed with the `vllm` extra (#87)

**Full Changelog**: [here](https://github.com/gepromptet/promptolution/compare/v2.3.0...v2.3.1)
